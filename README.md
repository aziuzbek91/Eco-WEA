# 🌿 Eco-WEA

A modern environmental awareness website developed using **HTML5**, **CSS3**, and **JavaScript**. The project provides information about environmental protection, ecological news, laboratories, stores, and educational resources through a clean and responsive user interface.

## 🔗 Live Demo

https://aziuzbek91.github.io/Eco-WEA/

## 📸 Preview

> Visit the live website using the link above.

## ✨ Features

- Responsive website design
- Environmental-themed user interface
- Home page with modern layout
- Navigation menu
- Search section
- Ecological news pages
- Laboratory information pages
- Shop pages
- Environmental image gallery
- Admin page
- Multi-page website structure
- Cross-browser compatibility

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
